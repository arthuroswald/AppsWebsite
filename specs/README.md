# Apps Website Specs

These files are the living product contracts for the public apps website.

## Screens

- `screens/home.md`: multi-app catalog.
- `screens/app-marketing.md`: app presentation.
- `screens/app-support.md`: support and contact.
- `screens/app-privacy.md`: privacy policy.

## Features

- `features/localization.md`: language detection and switching.
- `features/app-catalog.md`: multi-app content model.
- `features/navigation-and-routing.md`: stable public paths.
- `features/accessibility-and-responsive-design.md`: inclusive layouts and interaction.
- `features/seo-and-sharing.md`: discovery and social previews.

Read the relevant specs before changing user-visible behavior. Update them in the same
change when behavior, copy contracts, navigation, localization, accessibility, support,
privacy, or metadata changes.
