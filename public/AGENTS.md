# `public` Agent Guide

Only deployable public assets belong here.

- Group app assets under `public/apps/<app-id>/` and fonts under `public/fonts/`.
- Copy approved assets into this repository; never use symlinks or absolute paths to
  another repository.
- Record asset provenance and preserve third-party licenses.
- Use descriptive lowercase filenames and avoid unnecessary duplicates.
- Optimize large assets only when the visual result remains faithful to the source.
