# `src/components` Agent Guide

Shared components are reusable, accessible, and content-agnostic.

- Prefer composition and explicit typed props.
- Use semantic HTML, native links and buttons, visible focus, and meaningful labels.
- Do not import from `src/screens/` or hard-code app-specific public copy.
- Use theme tokens and colocated CSS Modules.
- Add a shared component only when reuse or a stable site-wide boundary is clear.
