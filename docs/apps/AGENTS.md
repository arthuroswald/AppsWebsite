# `docs/apps` Agent Guide

Product briefs are concise, factual snapshots of each source app.

- Separate verified decisions from proposals or missing information.
- Record the exact source repository commit and consultation date.
- Cover positioning, behavior, languages, store metadata, public-page needs, privacy
  facts, and reusable assets.
- Do not duplicate internal implementation details that are irrelevant to the website.
- Refresh a brief when public claims or store metadata materially change.
